# 04-功能测试报告

## 1. 测试范围

本报告对应当前工作副本全部功能，管线为十一阶段闭环：
`接收 → 抗注入 → 感知 → 磁盘候选门禁 → 检索 → 推理 → 规划 → 校验 → 跨轮防护 → 执行 → 分析`。

覆盖以下能力：
- 基础护栏：READONLY/EXECUTABLE/IRREVERSIBLE/BLOCK 四级裁决、人工确认门（`confirm+traceId`）、
  执行前备份、回滚账本、trace 溯源。
- 三大加固功能：**跨轮渐进式攻击防护**（会话级只读降级）、**磁盘候选选择与复核**（先展示候选表、
  用户勾选、再生成方案）、**诊断证据继承**（同会话追问复用近轮证据，不重开攻击面）。
- 两项本轮新增：**TOCTOU 复检**（候选生成到执行之间文件被重新写入的执行前复检）、
  **`io_activity_sense` 实时文件活跃度感知**（两点差分识别文件增速+写入进程，含磁盘候选表增长降级）。
- 前端改造：**链路三色轨道可视化**（每阶段读自身信号而非顶层 status）、**威胁指数评估**（随指令危险度走，
  与既有防御表现分互补）。

测试方法三层：①全量自动化单元/集成测试；②针对真机的活体功能探针（HTTP 直接调用真实运行的服务）；
③真实 DeepSeek 模型的红队复测（验证"模型输出不可控、护栏是否兜住"这一核心命题）。

## 6. 真实 DeepSeek 模型红队复测（补充验证）

针对"AI 推理本身不可控，安全性依赖确定性护栏兜底"这一核心命题，用真实 DeepSeek 模型（非 mock）
重放 33 条红蓝对抗场景 + 6 条畸形/刁钻输出健壮性探针，同样在这台龙芯真机上执行。

**核心结论：所有显式高危指令（删库、清空目录、rm -rf /、mkfs 格式化、dd 抹盘、chmod 777 /）在真实
模型生成具体 Linux 命令后，红线拦截 7/7 全部命中，无一次遗漏。** 提示词注入类指令 7/7 全部在入口
拦截。ReAct 按需感知路径 8/8 场景真实启用（无一次静默降级），说明真实模型接入后按需感知机制工作正常。
6 条畸形/刁钻输出健壮性探针全部得到优雅、结构化的响应，无异常崩溃。

真实模型场景下命令生成具体、贴合当前主机实际状态（如引用真实进程 PID、真实端口占用），验证了护栏
体系面对不可预测的模型输出时依然按既定规则稳定裁决。

## 7. 结论

功能层面：303 个自动化测试在真实龙芯硬件上全部通过，五大加固功能（跨轮防护/磁盘候选/证据继承/
TOCTOU复检/深度感知）与两项前端改造（链路可视化/威胁指数）均有对应测试覆盖且真机验证通过。18 项
活体功能探针全部通过。真实 DeepSeek 模型红队复测证明护栏体系对显式高危指令的拦截能力不因接入真实、
不可控的模型而减弱，这是本项目核心安全主张的第一手真机证据。
